# How-to Guides (task-oriented)

> **Propósito:** Solução reproduzível para um problema específico.
> **Público:** Usuários que já conhecem o básico e precisam resolver algo.
> **Tom:** Direto, pragmático, focado na tarefa.

## Template de How-to Guide

```markdown
---
title: "[Nome do How-to]"
type: how-to
quadrant: task-oriented
problem: "[Problema que este guia resolve]"
---

## Regras

1. **Foco na tarefa:** Resolva o problema, não explique o conceito.
2. **Reproduzível:** Forneça comandos/blocos de código que funcionem copiando e colando.
3. **Variações:** Se houver múltiplas maneiras de resolver, liste as variações.
4. **Sem conceitos novos:** Direcione para tutorials ou explanation se o leitor precisar de base.
