# Documentação — Índice

Guia de navegação da documentação do projeto, estruturada segundo o framework **Diátaxis** (4 quadrantes).

## Quadrantes

| Diretório | Quadrante | Orientação | Para quem |
|---|---|---|---|
| [`01-tutorials/`](./01-tutorials/README.md) | **Tutorial** | learning-oriented | Iniciantes, novos no projeto |
| [`02-how-to/`](./02-how-to/README.md) | **How-to Guide** | task-oriented | Usuários com problemas específicos |
| [`03-reference/`](./03-reference/README.md) | **Reference** | information-oriented | Desenvolvedores que precisam consultar |
| [`04-explanation/`](./04-explanation/README.md) | **Explanation** | understanding-oriented | Quem busca contexto e fundamentos |

## Regra de ouro

> **Nenhuma feature está completa sem documentação no quadrante apropriado.**

Consulte `.harness/tools/diataxis-docs.md` para o framework completo e a checklist de validação do agente REVIEWER.
