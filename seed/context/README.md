# .harness/context/

Contexto **compactado** do projeto, gerado e consumido pelas ferramentas (Repomix + RTK).

- `repo-packed.md` — pacote do repositório gerado pelo Repomix (regenerável, fora do git).
- Documentos de contexto derivados (architecture/decisions/lessons/patterns) podem ser materializados aqui a partir do `.gbrain/` quando se quer um snapshot compacto para uma execução.

> Conteúdo regenerável. O `install.sh` adiciona este diretório ao `.gitignore` do projeto.
